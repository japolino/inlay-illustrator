# Inlay Illustrator Workspace Boundary

All work for this project is restricted to this `inlay-illustrator` repository.

- Read, edit, create, build, test, commit, and push files only within this repository.
- Do not modify the parent Lumiverse checkout or any sibling repository.
- Push changes only to this repository's `staging` branch.
- If completing a request would require a change outside this repository, stop and ask for explicit direction instead of making that change.
